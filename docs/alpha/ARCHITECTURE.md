# STAR 架构

Core 与叙事无关、与链无关、与具体市场无关。

```text
Event → Narrative → Asset → Market → Money → Decision → Position → Re-evaluate → Exit
```

四个核心抽象：

1. Market Adapter — 当前只有 `U-01-SOLANA`
2. Narrative / Event Adapter — 绑定「注意力 → 新资产」，不预测下一个梗
3. Decision Engine — 只判断阻击窗口
4. Position / Exit Engine — 叙事是否还在、资金是否还在、结构是否失效

雷达三路：Narrative / Token / Money。Ave.ai 只可能做 Token Radar，不是市场本身。

组合目标不是高胜率，而是：大量候选、亏损封顶、不错过肥尾。

不接 BNB / BTC / Base / TON。不新开研究页。
